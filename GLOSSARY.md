# Raylı Sistemler Teknik Terimler Sözlüğü (Glossary)

Bu sözlük, rehber içerisinde kullanılan teknik terimlerin Türkçe ve İngilizce karşılıklarını içerir.

| Türkçe Terim | İngilizce Karşılık | Açıklama |
| :--- | :--- | :--- |
| **Boji** | Bogie / Truck | Tekerlek takımlarını taşıyan ve gövdeye yataklık eden yapı. |
| **Cer** | Traction | Aracın hareket etmesini sağlayan çekiş gücü. |
| **Katener** | Catenary | Elektrikli trenlere enerji sağlayan havai hat sistemi. |
| **Anklaşman** | Interlocking | Sinyal ve makaslar arasındaki emniyetli kilitleme sistemi. |
| **Makas** | Turnout / Switch | Trenin bir hattan diğerine geçmesini sağlayan mekanizma. |
| **Üçüncü Ray** | Third Rail | Genellikle metrolarda kullanılan zemin seviyesindeki enerji hattı. |
| **Balast** | Ballast | Traverlerin altına serilen, yükü dağıtan kırmataş tabakası. |
| **Aks Sayıcı** | Axle Counter | Trenin hattaki varlığını aksları sayarak tespit eden sistem. |
| **Ray Devresi** | Track Circuit | Raylar üzerinden elektrik akımı geçirilerek tren tespiti. |
| **Pantoğraf** | Pantograph | Katener hattından enerji alan akım toplama kolu. |
| **RAMS** | RAMS | Reliability, Availability, Maintainability, Safety. |
| **SIL** | Safety Integrity Level | Emniyet Bütünlük Seviyesi (1'den 4'e kadar). |
| **YHT** | High-Speed Train (HST) | Yüksek Hızlı Tren. |
| **ERTMS** | ERTMS | European Rail Traffic Management System. |
| **CBTC** | CBTC | Communication Based Train Control. |
